What if a link cannot be processed?

If GrabIt can't process a link, it will explain why in plain language:

  • Media not foundCheck the link and make sure the media is still public.
  • Private or protected mediaGrabIt does not access private content or bypass access controls.
  • File too largeThis direct file exceeds the current download limit.
  • Temporary server issueWait a moment, then try again.
  • Download unavailableThis option cannot be downloaded right now.
